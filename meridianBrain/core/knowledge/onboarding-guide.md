# Engineer onboarding

> **Meridian status (WIP — not wired):** Onboarding steps are valid for humans, but this file is **not** a `#file:` attachment in Copilot prompts today (use `/util-setup` / README). Optional future: attach here from `util-setup`.

1. Clone this repository.
2. Run `/util-setup` in Copilot.
3. Copy `core/config/local.json.example` to `core/config/local.json` and set your `platforms` array.
4. Run `npm install` in `core/scripts/workflow` if the setup prompt has not already done so.
5. Run `/util-sync` at the start of the day to pull and refresh tooling.
